五、半人工黏性的文献依据与正确理解
====================

你必须严格按下面的来源边界来理解并说明：

1. 【文献A正文】
   - 文献A明确说：当基流含激波时，加入 semi-artificial viscosity 稳定数值格式
   - 强度量级约 1e-2
   - 文献A正文没给精确公式

2. 【Hildebrand 2019】
   - 给出了具体 Filtering 方法
   - 说明 centered finite differences 缺少耗散
   - 说明需要 scale-selective artificial dissipation 来压 shortest resolvable wavelengths
   - 说明真正用于 GSA/TGA 的是四阶滤波：
     Fstr * (-phi_{j+2} + 4phi_{j+1} - 6phi_j + 4phi_{j-1} - phi_{j-2})
   - 说明该滤波加在 Jacobian operator 的 main block diagonal 上
   - 典型 Fstr 约 0.0125

3. 【必须坚持的解释】
   - 半人工黏性不是物理黏性
   - 不是改 mu，不是改基流
   - 不是改连续方程物理推导
   - 它是离散层附加滤波矩阵

====================
六、你必须采用的实现方向
====================

你要把半人工黏性实现为：

Ktotal = Kcore + eps_av * Kav

或等价地：

Ntotal = Ncore + eps_av * Kav

这里：
- Kcore / Ncore：原来的核心离散稳定性矩阵
- Kav：新加的半人工黏性矩阵
- eps_av：小参数，初值取 1e-2 附近

### 6.1 Kav 的结构要求
Kav 必须满足：

1. 只作用于四个变量各自的方程：
   - rho' 方程加 F_av(rho')
   - u' 方程加 F_av(u')
   - v' 方程加 F_av(v')
   - T' 方程加 F_av(T')

2. 不新增跨变量耦合：
   - 不要把 rho' 滤波加到 u' 列
   - 不要把 u' 滤波加到 T' 列
   - 每个变量只滤自己

3. 在二维网格上使用“十字形五点四阶滤波模板”，分别在 x/xi 和 y/eta 两个方向叠加

### 6.2 你需要优先尝试的滤波模板
对任意一个变量分量 phi，在内部点 (i,j) 处定义：

F_av(phi)_{i,j}
=
(-phi_{i+2,j} + 4phi_{i+1,j} - 6phi_{i,j} + 4phi_{i-1,j} - phi_{i-2,j})
+
(-phi_{i,j+2} + 4phi_{i,j+1} - 6phi_{i,j} + 4phi_{i,j-1} - phi_{i,j-2})

也就是说，对每个内部点的同变量块，加如下系数：

- (i-2,j): -eps_av
- (i-1,j): +4eps_av
- (i,j):   -12eps_av
- (i+1,j): +4eps_av
- (i+2,j): -eps_av
- (i,j-2): -eps_av
- (i,j-1): +4eps_av
- (i,j+1): +4eps_av
- (i,j+2): -eps_av

注意：
- 这是在单变量模板层的系数
- 四变量系统里对应的是这些系数乘以同变量单位块
- 不要引入跨变量滤波耦合

### 6.3 启用区域
第一版只在内部点启用滤波：

- i = 3 ... Nx-2
- j = 3 ... Ny-2

边界前两层、接口点、特殊边界替换行先不要加这个滤波，除非你在审计后确认已有一致的边界滤波模板。

则认为这轮改动是正向的。

- 主模态大幅漂移
- 主模态空间结构被明显改坏
- 原来“主模态”完全消失

则优先判断为：
- 当前谱被伪模态严重污染，或
- Kav 装配位置/符号/索引错误，或
- 核心矩阵/边界条件本身仍有问题
