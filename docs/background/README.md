# Background Notes

这个目录存放仍有参考价值、但不属于“当前执行日志”的背景材料。

放在这里的文件通常包括：
- 一轮或多轮静态调查报告
- 文献调研与方法对比
- 需要长期保留的背景分析笔记

不应该继续放在这里的内容：
- 当前任务的待办和下一步计划
  - 统一写到 `docs/coordination/WORK_QUEUE.md`
- 任务完成记录
  - 统一追加到 `docs/coordination/TASK_LOG.md`
- 重大技术变更和验证结论
  - 统一追加到 `docs/audit.md`
- 一次性 debug/fix 临时日志
  - 如果已被 `audit` 或 `TASK_LOG` 吸收，应直接删除，不再单独保留
