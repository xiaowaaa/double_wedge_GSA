## 2. 你的方法的最终定位

### 2.1 四变量系统的清晰定义
你当前方法的核心未知量是：

\[
q'=
\begin{bmatrix}
\rho'\\
u'\\
v'\\
T'
\end{bmatrix}.
\]

核心连续系统可写为：

\[
\Gamma q_t + A q_x + B q_y + Dq
=
V_{xx}q_{xx}+V_{xy}q_{xy}+V_{yy}q_{yy},
\]

或其贴体/计算坐标版本：

\[
\Gamma q_t + A_\xi q_\xi + B_\eta q_\eta + D' q
=
V_{\xi\xi}q_{\xi\xi}+V_{\xi\eta}q_{\xi\eta}+V_{\eta\eta}q_{\eta\eta}.
\]

其中压力扰动通过状态方程消去。  
【基于文献的合理推论：这里是你方法的已知理论框架，不是文献A/B原文】

### 2.4 与文献A/B比较时的统一记号约定

### 3.2 稳定性变量与双全局形式

\[

\[

\[
A(\bar q;\beta)\hat q=\omega B\hat q.
\]

【文献A正文】

## 5. 海绵层与半人工黏性的单独归档

### 5.1 海绵层：文献A、Mani 2012、Hildebrand 2019 各自提供了什么

#### 文献A提供了什么
- 海绵层存在  
- 布置在远场和出口附近  
- 目的是抑制扰动反射  

【文献A正文】

#### Mani 2012 提供了什么
Mani 2012 给出海绵层的核心思想：

\[
\partial_t U+\cdots = r(U_{ref}-U).
\]

围绕基本流线性化后变为：

\[
-rU'.
\]

因此海绵层本质上是：

- 局部零阶阻尼  
- 边界吸收层  
- 用于减少边界反射污染  

【Mani 2012】

#### Hildebrand 2019 提供了什么
Hildebrand 2019 自己也用了海绵层，并给出了平滑阻尼函数形式，说明这一路线的稳定性求解器通常会把海绵层实现成：

- 边界附近局部阻尼层  
- 平滑增强剖面  

【Hildebrand 2019】

### 5.2 半人工黏性：文献A、Hildebrand 2019 各自提供了什么

#### 文献A提供了什么
- 存在 semi-artificial viscosity  
- 用于含激波基流下稳定数值格式  
- 强度量级约 \(10^{-2}\)  

【文献A正文】

#### Hildebrand 2019 提供了什么
Hildebrand 2019 的 3.5 Filtering 明确给出：

1. 为什么要加滤波  
   - centered finite differences 缺少耗散  
   - under-resolved Fourier components 会传播而不衰减  

2. 二阶滤波机理模型  
   \[
   \frac{d\phi_j}{dt}=F_{str}(\phi_{j+1}-2\phi_j+\phi_{j-1})
   \]
   对应 Fourier 衰减率：
   \[
   \frac{dA}{dt}=-2F_{str}[1-\cos(k\Delta x)]A
   \]

3. 真正用于 GSA/TGA 的是四阶滤波  
   \[
   F_{str}(-\phi_{j+2}+4\phi_{j+1}-6\phi_j+4\phi_{j-1}-\phi_{j-2})
   \]

4. 该滤波加在 Jacobian operator 的 main block diagonal 上  

5. 典型强度  
   \[
   F_{str}\approx 0.0125
   \]

【Hildebrand 2019】

### 5.3 统一结论：在你的方法里应该如何理解
对你当前四变量高阶差分方法来说，最准确的理解是：

#### 海绵层
- 是边界附近的局部阻尼层  
- 作用是抑制边界反射  
- 应理解为离散层零阶阻尼块  

#### 半人工黏性
- 不是物理黏性  
- 不是改基流  
- 不是改连续系数矩阵的物理含义  
- 是加在离散稳定性矩阵上的弱四阶滤波器  
- 主要压制高波数/锯齿型伪模态  

### 5.4 严格区分“原文内容”和“合理推论”
后续写理论或代码说明时，必须明确区分：

**原文内容**
- 文献A中海绵层与半人工黏性的功能与存在性  
- Mani 2012 的海绵层源项理论  
- Hildebrand 2019 的四阶滤波模板与参数  

**合理推论**
- 把 Hildebrand 的滤波模板映射到你四变量系统的块稀疏矩阵  
- “含高频成分的伪模态会被更强压制”  
- “先保留四变量框架做第一轮谱修复是合理的”

## 6. 对后续代码重构最有用的结论

### 6.1 为什么主参考应当是文献A
因为你当前代码框架与文献A在以下方面最接近：

- 连续方程可对齐  
- 高阶有限差分路线一致  
- 全局稳定性问题组织方式更接近  

而文献B在实现路线上的差异太大，不适合作为当前重构主模板。

### 6.2 为什么先保留四变量框架是合理的
因为已经明确：

- 你的四变量系统与文献A在连续层本质兼容  
- 当前更急迫的问题是谱污染与高频伪模态  
- 这些问题可在四变量框架内先处理  

因此更合理的路线是：

1. 先保留四变量框架  
2. 先修谱质量  
3. 再决定是否升级为五变量双全局系统  

### 6.3 为什么半人工黏性优先于海绵层
因为当前两类问题应当分开处理：

- 海绵层：边界反射问题  
- 半人工黏性：高频伪模态问题  

当前更适合第一轮优先做的是：

\[
\boxed{
\text{先加半人工黏性清理谱，再视情况决定是否加入海绵层。}
}
\]

### 6.4 什么现象应判定为伪模态/谱污染
后续看谱时，以下现象应高度警惕：

- 棋盘格/锯齿型空间结构  
- 仅沿一条网格线强烈振荡  
- 明显边界局部化  
- 对很小人工滤波极度敏感  

反过来，如果加入 \(10^{-2}\) 量级的弱滤波后：

- 高频脏谱明显后退  
- 主模态变化很小  

则通常说明原来那批模式很可能是伪模态。

### 6.5 哪些改动必须分阶段做
最合理的后续修改顺序是：

1. 先审计核心矩阵与边界行  
2. 再加半人工黏性  
3. 再做谱质量检查  
4. 再决定是否加海绵层  
5. 最后再考虑是否升级到五变量双全局系统
